## 파일

- `Instagram 콘텐츠 템플릿.dc.html` — 정본 템플릿 (5개 섹션: story/reels/carousel/feed/highlight). **직접 수정 금지 — 사본으로 콘텐츠 제작.**
- `IGSafeZoneOverlay.dc.html` — 세이프존 오버레이 컴포넌트. props: `visible`, `kind: "story" | "reels" | "carousel" | "feed"`. QA 때 켜고, 내보낼 땐 끈다.
- `support.js`, `image-slot.js` — DC 런타임 지원 스크립트 (사본에 함께 복사).
- `../tokens.css` → 저장소 `shared/tokens.css`, `../../../shared/local-design.global.js` — 공통 토큰과 `LOCALDS` 컴포넌트.

## 사용 및 검수

저장소 루트 README의 설치·실행 절차를 먼저 진행하세요. 위 수치는 템플릿에 구현된 검수 가이드이며 플랫폼의 최신 공식 규격을 보증하지 않습니다. 실제 앱의 UI와 크롭 결과도 확인하세요.

템플릿 전체 채널 폴더를 같은 깊이의 `../output/`으로 복사하면 상대 경로가 유지됩니다. 원본 템플릿은 보존하고 사본의 문구와 이미지만 바꾸세요. 다른 위치로 옮길 때는 공통 자산까지 포함해 경로를 맞춰야 합니다.

Sample Studio 및 모든 수치·행사·후기는 가상 예시입니다. 사진 슬롯에 사용할 권리가 있는 이미지를 넣고, 후기는 실제로 제공받은 문장으로 교체하세요. 브랜드 워터마크는 `brandWatermark`, 가이드 초기 상태는 `showSafeZoneDefault`로 조절합니다. 스위치와 `IGSafeZoneOverlay`의 `visible`/`kind` 속성은 원본과 같습니다.
