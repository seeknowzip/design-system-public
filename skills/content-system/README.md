# Content System

인스타그램 이미지 콘텐츠를 만드는 템플릿과 검수 지침입니다. 공통 디자인 토큰·컴포넌트는 저장소의 `shared/`를 사용하고 콘텐츠 전용 구성과 세이프존은 이 폴더에서 유지합니다.

1. [채널 규격과 사용법](instagram/README.md)을 읽습니다.
2. 에이전트에 [SKILL.md](SKILL.md)를 읽고 템플릿 사본을 만들도록 요청합니다.
3. 본문·사진을 교체하고 세이프존을 켜서 검수한 뒤, 가이드를 끄고 내보냅니다.

기본 브랜드는 Sample Studio입니다. 일정·참가 수치·팀명·후기 등은 전부 가상 예시이며 실제 정보로 바꿔야 합니다. 예시 사진과 외부 브랜드 로고는 포함하지 않습니다.

슬라이드는 [Deck System](../deck-system/SKILL.md), 웹·앱은 [저장소 README](../../README.md)를 참고하세요. 문구 윤문에는 별도 [Writing System](https://github.com/seeknowzip/writing-system-public)을 선택적으로 사용할 수 있습니다.
