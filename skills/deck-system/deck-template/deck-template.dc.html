How to use

이 견본집 사용법

01
필요한 레이아웃만 복제하세요

왼쪽 슬라이드 목록에서 오른쪽 클릭 → 복제. 안내 슬라이드(02~05, 37~40)를 지우고 쓰지 않는 레이아웃을 삭제하면 그대로 완성된 문서가 됩니다.

02
본문 텍스트는 직접 고쳐 쓰세요

모든 문구는 화면에서 바로 클릭해 수정할 수 있어요. 예시 숫자는 실제 수치로 교체하면 됩니다.

03
사진은 자리에 끌어다 놓으면 채워져요

회색 이미지 자리에 파일을 드래그하면 바로 들어갑니다. 체육관·경기·샘플시 자원 사진을 권장해요.

04
색과 글자 크기는 한 번에 조절돼요

Tweaks에서 포인트 컬러·글자 배율·영문 병기 표시를 바꾸면 전체 슬라이드에 함께 적용됩니다.

Problem & Solution

샘플시는 지나가는 곳이었습니다

현재
머물 이유가 없는 방문
  • —관광객 체류 시간이 짧아 소비가 지역에 남지 않습니다
  • —주중 체육시설 가동률이 낮은데도 주말 수요는 흩어져 있습니다
  • —업체별로 흩어진 예약 절차가 팀 단위 방문의 문턱이 됩니다
샘플의 해결
팀 단위로 오게 하고, 하루를 더 남게
  • —샘플컵 대회로 한 번에 20팀 300명의 방문 수요를 만듭니다
  • —체육관 대관에 온천·장어 코스를 묶어 1박 2일로 늘립니다
  • —팀별 맞춤 일정 페이지로 예약 동선을 한 곳에 모읍니다
Our position

샘플은 대회를 여는 회사가 아니라,
샘플시에 올 이유를 만드는 회사입니다

생활체육을 매개로 외지인의 첫 방문을 만들고, 지역 소비와 재방문으로 연결합니다.
